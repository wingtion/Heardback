# JobTrail web

Angular frontend for JobTrail. See the [root README](../README.md) for the full picture.

```bash
npm ci
npm start          # dev server on http://localhost:4200, talks to the API on http://localhost:5080
npm test           # unit tests (Vitest), watch mode
npm run lint       # angular-eslint
npm run format     # Prettier (format:check verifies only)
npm run build      # production build into dist/
```
